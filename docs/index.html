Set it up in 6 steps

Trinetra is built from source for now, so you need macOS 13 or later, Xcode 16 and a free Apple ID signing team. A notarized download is on the roadmap. The video below walks through every step, made with HyperFrames.

  1. Install the CLI

    Clones the repo and builds trinetra into ~/.local/bin.

    git clone https://github.com/animeshbasak/trinetra.git
cd trinetra && scripts/install-cli.sh

  2. Connect your agents

    Adds Trinetra's hooks next to yours, after backing up each config. Codex asks you to trust new hooks once: run codex, then /hooks.

    trinetra hooks install claude
trinetra hooks install codex
trinetra hooks install gemini
trinetra hooks install cursor

  3. Build the app and move it to Applications

    Open the project, pick your signing team on both targets and press Run. The helper registers reliably only from /Applications, so copy the build there.

    open Trinetra.xcodeproj
pkill -x Trinetra; ditto ~/Library/Developer/Xcode/DerivedData/Trinetra-*/Build/Products/Debug/Trinetra.app /Applications/Trinetra.app && open /Applications/Trinetra.app

  4. Turn on lid mode

    Click the eye in the menu bar and switch on Keep awake with the lid closed.

  5. Allow the helper once

    In System Settings › General › Login Items › Allow in the Background, switch on Trinetra. It may be listed under your name. You never type a password per session.

  6. Turn on the monitor (optional)

    Switch modules on in the menu, or from the terminal. Allow notifications when macOS asks, so health alerts can reach you.

    trinetra modules enable system-monitor
trinetra modules enable health-alerts

Built on your agents' own hooks

Each agent runs one tiny command at the moments that matter. It writes a line to a local file and exits 0 in milliseconds. It never blocks, never answers a permission prompt, never fails the agent.

# one command per agent, backs up your config first
trinetra hooks install claude
trinetra hooks install codex
trinetra hooks install gemini
trinetra hooks install cursor

# what each hook runs
trinetra hook claude working
  • Backs up first to <file>.trinetra.bak
  • Leaves your hooks alone. Only Trinetra's entries change
  • Idempotent, and uninstall removes every trace
  • No prompt text stored. Only labels like a file name

Lid-closed mode without a sudoers rule

On battery, macOS sleeps on lid close no matter what. The only switch is pmset disablesleep, which needs root. Trinetra's helper exposes exactly that switch and nothing else.

  • Fixed commands only: pmset -a disablesleep 0 or 1. No shell
  • Code-signature checked: only the signed Trinetra app can call it
  • Reverts on disconnect: quit, crash or rebuild restores normal sleep
  • Dead-man switch: 2 minutes without a heartbeat and it reverts
  • Approved once in Login Items. No password per session

What it is, why it exists, how it was made

What

A small macOS menu bar app and CLI that holds your Mac awake, lid closed included, exactly while your AI agents are working, then lets it sleep.

It also tells you what each agent did and what the Mac was doing while you were away.

Why

Remote Control lets you drive Claude Code or Codex from your phone, but only while the Mac is awake. Close the lid and the session dies.

caffeinate and Amphetamine don't know when your agents finish and can't stop lid-close sleep on battery. Some lid tools rely on a sudoers rule. I wanted something that watches the agents and holds the narrowest possible privilege.

How

Swift and SwiftUI, a pure, unit-tested decision function, the agents' own hooks, and a single-purpose root helper approved once through SMAppService.

Designed and directed by me, built with Claude Code: the same kind of agent Trinetra keeps awake.

FAQ

How do I keep my MacBook awake with the lid closed without an external display?

Turn on Keep awake with the lid closed in Trinetra and approve its helper once in System Settings › General › Login Items. While an agent is working or a timer runs, closing the lid won't sleep the Mac, on battery too. When the work ends, normal sleep comes back by itself.

Does Claude Code Remote Control keep working when I close the lid?

Only while the Mac is awake. A sleeping Mac drops the session. With lid mode on, Remote Control and similar sessions keep running with the lid shut while the agent works.

How is Trinetra different from Amphetamine, Caffeine or caffeinate?

Those keep the Mac awake until you stop them and can't block lid-close sleep on battery. Trinetra holds only while your agents are working, covers the lid, then releases, so it doesn't drain your battery overnight.

Is it safe to run a closed MacBook?

It uses power and makes heat. Use a hard, ventilated surface, never a closed bag. Trinetra's 10 % battery floor and thermal cutout can't be turned off.

What does the system monitor show, and does it cost battery?

CPU per core, GPU, memory and pressure, temperatures, battery health and power draw, network and disk, plus the CPU each agent uses. It samples every 10 seconds in the background and every 2 seconds while the menu is open or a menu bar readout is on. Switched off, it runs nothing.

Why build from source instead of downloading an app?

Shipping a ready-made download needs Apple notarization, which needs a paid developer account. Until then, the six steps above build it in Xcode with a free signing team.

Does Trinetra read my prompts or code?

No. Hooks record the agent, the project folder name, the state and a short label such as a file name. No telemetry, no network calls.
